Textbook Cheat Sheet

1. Making Comparisons

Short adjectives: -er + than (e.g., harder than)

الصفات القصيرة: نضيف -er ثم than (مثال: harder than)

Longer adjectives: more + adjective + than (e.g., more exciting than)

الصفات الطويلة: more + الصفة + than (مثال: more exciting than)

Never both: ✗ more harder → ✓ harder than

لا نجمع بين الاثنين: ✗ more harder ← ✓ harder than

Example: I think that board games are harder than video games.

2. Like / Would like

Like: general preferences

like: للتفضيلات العامة

Examples: I like many different kinds of games. I like reading books.

Would like / I'd like: specific things we want, or want to do

would like / I'd like: للطلبات أو الرغبات المحددة

Examples: I'd like to watch the latest cartoon. I'd like two tickets, please.
