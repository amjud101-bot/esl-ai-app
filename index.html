Textbook Cheat Sheet

1. Making Comparisons

Short adjectives: -er + than (e.g., shorter than)

Long adjectives: more + adjective + than (e.g., more exciting than)

2. Like / Would like

Like: General preferences (للتفضيلات العامة)

Example: I like reading books.

Would like / I'd like: Specific requests/desires (للطلبات أو الرغبات المحددة)

Example: I'd like two tickets, please.
