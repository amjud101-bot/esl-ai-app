Grammar 2 Reference Sheet

1. Making Comparisons (المقارنة)

Short Adjectives: -er + than

Example: I think that board games are harder than video games.

Longer Adjectives: more + adjective + than

Example: I think that video games are more exciting than board games.

2. Like / Would like (التفضيل والطلب)

Like: Used to talk about general preferences (التفضيلات العامة).

Examples: I like many different kinds of games. / I like reading books.

Would like / I'd like: Used to talk about specific things we want or want to do (طلبات أو رغبات محددة).

Examples: I'd like to watch the latest cartoon. / I'd like two tickets, please.
